# Museum Booking Hub 3D

Gestione delle prenotazioni e visita virtuale 3D di un museo. Project work — traccia 22, *Digitalizzazione dei processi aziendali in un'impresa culturale*.

Il visitatore sceglie un itinerario, una data e una fascia oraria, poi seleziona i posti direttamente in una **mappa 3D** del salone e prenota. L'amministratore gestisce
itinerari, prenotazioni, utenti, feedback e consulta le statistiche. Prima del progetto le prenotazioni si facevano per telefono ed e-mail, con liste cartacee e registri locali
(vedi i diagrammi in `docs/`).
